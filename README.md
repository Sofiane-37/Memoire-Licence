# Memoire-Licence
Ce dépôt contient mon mémoire de fin d'études portant sur l'influence des langages de programmation sur l'efficacité des algorithmes, réalisé dans le cadre de ma Licence Informatique (promotion 2025–2026).

L'objectif de cette recherche était d'analyser l'impact des paradigmes et des mécanismes de bas niveau (gestion mémoire, compilation vs interprétation) sur la vitesse d'exécution et la consommation de ressources, afin de déterminer dans quelle mesure le choix d'un langage peut devenir un goulot d'étranglement ou un levier stratégique pour la performance algorithmique brute.
